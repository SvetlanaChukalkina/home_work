# Виджет банковских операций (в разработке) 
Цель проекта: создание виджета, показывающего несколько последних успешных банковских операций клиента. 
Виджет состоит из модулей masks, widget, processing. В каждом модуле реализованы функции для работы с данными клиента.

## Модуль masks содержит функции get_mask_card_number и get_mask_account

+ get_mask_card_number 
Функция get_mask_card_number маскирует номер банковской карты: принимает на вход номер карты и возвращает ее маску. 
Номер карты замаскирован и отображается в формате XXXX XX** **** XXXX, т.е. видны первые 6 и последние 4 цифры, остальные отображаются звездочками, номер разбит на блоки по 4 цифры, разделенные пробелами. 
Пример работы функции: входной аргумент - "7000792289606361", выход функции - "7000 79** **** 6361"

+ get_mask_account 
Функция get_mask_account маскирует номер банковского счета: принимает на вход номер счета и возвращает его маску. 
Номер счета замаскирован и отображается в формате **XXXX, т.е. видны последние 4 цифры номера, а перед ними — две звездочки. 
Пример работы функции: входной аргумент - "73654108430135874305", выход функции - "**4305"

## Модуль widget содержит функции mask_account_card и get_date

+ mask_account_card
Функция mask_account_card принимает строку, содержащую тип и номер карты или счета и возвращает строку с замаскированным номером. 
Пример работы функции для карты: входной аргумент - "Visa Platinum 7000792289606361", выход функции - "Visa Platinum 7000 79** **** 6361"
Пример работы функции для счета: входной аргумент - "Счет 73654108430135874305", выход функции - "Счет **4305"

+ get_date
Функция get_date принимает на вход строку с датой в формате "2024-03-11T02:26:18.671407" и возвращает строку с датой в формате "ДД.ММ.ГГГГ".
Пример работы функции: входной аргумент - "2024-03-11T02:26:18.671407", выход функции - "11.03.2024"

## Модуль processing содержит функции filter_by_state и sort_by_date

+ filter_by_state
Функция filter_by_state принимает список словарей и опционально значение для ключа state (по умолчанию "EXECUTED"), возвращает новый список, содержащий словари с ключом state, соответствующим указанному значению.
Пример работы функции: входной аргумент - [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
выход функции (статус по умолчанию "EXECUTED") - [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
выход функции (аргумент "CANCELED"): [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

+ sort_by_date
Функция sort_by_date принимает список словарей и необязательный параметр, задающий порядок сортировки (по умолчанию — убывание), возвращает новый список, отсортированный по дате.
Пример работы функции: входной аргумент - [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
выход функции: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]

## Тестирование модулей

### Тестирование модуля masks

+ Тестирование функции get_mask_card_number: реализованы тесты правильности маскирования номера карты и
работы функции на различных входных форматах номеров карт, проверка корректной обработки входных строк, 
где отсутствует номер карты.

+ Тестирование функции get_mask_account: тесты для проверки правильности маскирования номера счета
и для проверки работы функции с различными форматами номеров счетов. 
Функция корректно обрабатывает входные данные, где номер счета меньше ожидаемой длины.

### Тестирование модуля widget

+ Тестирование функции mask_account_card: реализованы тесты для проверки, что функция корректно распознает 
и применяет нужный тип маскировки, а также обрабатывает некорректные входные данные. Проведены 
параметризованные тесты с разными типами карт.

+ Тестирование функции get_date: проверка правильности преобразования даты и работы функции 
на различных входных форматах даты. Функция корректно обрабатывает входные строки, где отсутствует дата.

### Тестирование модуля processing

+ Тестирование функции filter_by_state: протестирована фильтрация списка словарей по заданному статусу 
state, проведена проверка работы функции при отсутствии словарей с указанным статусом state в списке.
Применена параметризация тестов для различных возможных значений статуса state.

+ Тестирование функции sort_by_date: реализовано тестирование сортировки списка словарей по датам 
в порядке убывания и возрастания, а также работы функции с некорректными форматами дат.
При одинаковых датах функция работает корректно.
